prefix+letters: Our own actor: a new SD prefix and a state edit, the SDBL/SDGL pattern. MISL cannot simply be overridden: it is one sprite for two rockets, and Freedoom's MISL A has 5 rotation lumps whose names would have to match ours one for one. The shared burst gets its own name, SDPX, so the PG-7V and the Katyusha draw the same three lumps; its letters move from MISL B-D to SDPX A-C (a sprite must start at A), tics unchanged.

rename: Our own actor, letters and tics as they are: PLSS -> SDFJ and PLSE -> SDFX is a rename of the sprite only. MOD-SPEC 6.3 reserves SDFL for the flight; SDFJ ('flame jet') is proposed instead because SDFL plus frame R and rotation 1 spells SDFLR1, the name of an installed floor flat (different namespaces, so not an engine clash, but a reader's one). SDFX as reserved. RenderStyle Add, Alpha 0.85 stay.

override: An engine actor: ship the IWAD's own lump names (every frame, all rotation 0, so nothing of Freedoom's is left to mix in). No ZScript: it reaches every path that spawns the actor, including SD_IceAxePuff (it inherits BulletPuff's PUFF states), the engine's own blood with the D49 BloodColor, the teleport fog the General spawns, and the barrels and lamps the maps place by ednum. A new prefix would need a replacing class per actor plus SD_IceAxePuff's states, for the same pixels.
