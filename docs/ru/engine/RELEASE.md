Гейт G6 (`docs/ROADMAP.md`): **файл лицензии, титры, README EN/RU,

## 1. Сборка пакета

```bash
.venv/Scripts/python.exe tools/release.py --version 1.0   # Windows; python3 on the Mac
# -> dist/release/sovietdoom-1.0.zip and dist/release/sovietdoom-1.0.zip.sha256
```

`dist/` в gitignore (`.gitignore`, строка 2), поэтому пакет никогда не
попадает в репозиторий. `--version` обязателен (`1.0`, `1.0.1`, `1.0-rc1`;
без ведущего `v`: тег — `v1.0`, версия — `1.0`). Инструмент отказывается
работать с деревом, где есть незакоммиченные или неотслеживаемые изменения:
релиз делается из коммита, чтобы zip можно было проследить до него.
`--allow-dirty` существует **только для набора тестов**
(`tests/test_release.py`); пакет, сделанный с ним, пишет `+dirty` после
коммита в `CREDITS.txt` и `README.txt` и ни в коем случае не должен
раздаваться.

### 1.1 Что лежит в zip

Одна папка, `sovietdoom-<version>/`, ровно с пятью файлами:

| Файл | Откуда берётся |
|---|---|
| `sovietdoom.pk3` | `tools/build.py` по выгруженному дереву, та же сборка, что делает CI |
| `LICENSE.md` | `LICENSE.md` репозитория, байт в байт |
| `CREDITS.txt` | генерируется: титры в игре (`SD_CRED_*` из собственного `LANGUAGE` PK3, сначала английский, потом русский, в порядке экрана); строки, которые `docs/sound/MUSIC-RIGHTS.md` §4.5 велит воспроизводить дословно; по записи на каждую строку реестра, покрывающую упакованный ассет (файлы, происхождение, лицензия, а для музыки — обязательство из §4.5) |
| `README.txt` | генерируется: короткое руководство игрока на английском и русском: что это, оговорка D46, что скачать (GZDoom ≥ 4.14.2, D3; Freedoom: Phase 2, проверено на 0.13.0, D2; **IWAD не входит в пакет**), как запустить, основное управление. Названия карт и меню читаются из `LANGUAGE`, так что руководство называет вещи так же, как игра |
| `SHA256SUMS` | формат `sha256sum -c`, для четырёх файлов выше |

Рядом с zip файл `sovietdoom-<version>.zip.sha256` хранит хеш самого zip,
для страницы релиза.

### 1.2 От чего он отказывается (выход 1, ничего не записано)

- Грязное дерево без `--allow-dirty`; неверная или отсутствующая версия.
- **Упакованный ассет без строки лицензии.** «Ассет» — это каждый файл в
  папках, которые проверяет `tools/check_pk3.py` (`textures/`, `flats/`,
  `sprites/`, `sounds/`, `music/`, `graphics/`, `patches/`, `hires/`,
  `fonts/`). Строже, чем `check_pk3`: ассет должен быть назван в **первой
  ячейке строки таблицы** `docs/art/LICENSES.md`, у которой есть столбец
  Licence; имя в абзаце ничего не лицензирует. Токен с `/`
  (`fonts/bigfont/*.png`) покрывает эту папку и ничего больше. **Музыке**
  дополнительно нужна строка в `docs/sound/MUSIC-RIGHTS.md` §4.5, таблице
  «что отправляется».
- **Лицензия, требующая указания авторства, чьё имя отсутствует в титрах, на
  английском и на русском.** Имена берутся из реестров: `credit "Name"` в
  ячейке лицензии; иначе, для ячейки, где сказано credit,
  `{{Attribution…}}`, CC BY, BSD, MIT или OFL, — каждое имя, выделенное
  жирным, в строке; `idem` повторяет строку выше; наши собственные строки
  (D15) требуют «Soviet Doom» и «CC BY-NC-SA 4.0»; обязательство §4.5
  «credit Name» тоже считается. Строка, которой нужен кредит и которая не
  называет никого, — ошибка. CC0 — вежливость: отсутствующее имя из
  вежливости — предупреждение. Проверяются строки `SD_CRED_*` — это и экран
  в игре, и верх `CREDITS.txt`, так что файл и игра никогда не расходятся;
  список происхождения ниже за кредит не считается.
- Всё из `work/`, `tools/`, `tests/`, `logs/`, `iwads/`, любое превью, любой
  IWAD (по его магическому числу `IWAD`, где бы он ни прятался), `.wad` вне
  `maps/` или WAD карты, не являющийся PWAD, — в PK3 или в zip.
- PK3, который отвергает `tools/check_pk3.py`.

### 1.3 Детерминизм

Тот же коммит, тот же zip, байт в байт (`tests/test_release.py` собирает его
дважды и сравнивает). Записи отсортированы; каждая запись несёт собственное
время коммита (UTC) как дату; система «создано на» и права зафиксированы
(модуль zip иначе писал бы 0 на Windows и 3 в остальных местах); сборка PK3
уже воспроизводима (`tools/sdbuild/pk3.py`). Между двумя машинами байты всё
же могут отличаться, если git выгружает текстовые файлы с разными концами
строк; релиз делать на одной машине (Windows-ПК, D27).

### 2.1 Риски, которые нужно снять до тега

- **Шрифт Impact в текстурах с текстом.** `docs/art/LICENSES.md` («Fonts used
  to rasterise Cyrillic text») фиксирует позицию, что растрированные пиксели
  лицензией шрифта не покрываются, как **НЕ ПРОВЕРЕНО юристом**, и предлагает
  чистый путь: пересобрать с шрифтом OFL и получить повторное одобрение CEO.
  `qa-engineer` решает на подписи, спрашивать ли.
- **Черновики — не содержимое v1.** `tools/make_draft_overlay.py` упаковывает
  черновики в `work/overlays/`, которого релиз никогда не касается; всё, что
  должен получить игрок, сначала нужно утвердить в `assets/` с его строкой
  реестра.
- **CI не запускает `tools/release.py`.** Набор тестов запускает его (дважды)
  на каждый push через `tests/test_release.py`, с семантикой
  `--allow-dirty`; сам отказ при чистом дереве проверяется только с
  подставным состоянием git.

## 3. Соглашения, на которые опирается инструмент

Для реестров арт-директора и звукорежиссёра, чтобы новая строка читалась
правильно:

- Помещать имя лампа (или токен папки вроде `fonts/<name>/*.png`) в обратные
  кавычки в **первой ячейке** строки таблицы, у которой есть столбец Licence
  (или «Origin and licence»).
- Когда лицензия обязывает указать автора, писать это как
  `credit "Name" is required` в ячейке лицензии. Имена, выделенные жирным в
  строке, тоже работают; строка, которой нужен кредит и которая не называет
  никого, останавливает релиз.
- Новая музыка: строка в LICENSES.md § Music **и** в MUSIC-RIGHTS §4.5, с
  ячейкой Obligation, содержащей либо `credit Name`, либо `none`.
- Затем добавить имя в строки `SD_CRED_*` на обоих языках
  (`tests/test_credits.py` уже требует этого для экрана).
