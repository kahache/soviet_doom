лозунги, объявления гражданской обороны и несколько сухих бюрократических
иронических ходов (D11: серьёзный тон; ирония — в канцелярите, никогда не

Ни один референс не говорит по-русски, поэтому может просочиться акцент
(исследование §2 от 2026-10-20). Поэтому у каждой реплики три дубля: t01
(exaggeration 0,5, cfg 0,5, temperature 0,7), t02 (0,6, 0,3, 0,75) и **t03 с
cfg 0** (0,45, 0, 0,7), документированное средство от межъязыкового акцента.

Генерация (ПРОВЕРЕНО, 2026-10-23): Chatterbox Multilingual в собственном
Python сервера, в рабочем процессе (HTTP-сервер не нужен), **на GPU** (CUDA
сработала; запасной вариант на CPU не понадобился), с фильтром речевых токенов
из `voice_takes/p2/gen_p2.py` (специальные токены >= 6561 отбрасываются до
S3Gen) и потолком в 400 речевых токенов (16 с). Русский расстановщик ударений
модели (`russian_text_stresser`) не установлен, а скачивать ничего нельзя,
поэтому текст отправляется с **ударениями, расставленными вручную** (U+0301,
который в словаре модели есть, ПРОВЕРЕНО); журнал и страница показывают
простой текст. Офлайн: `HF_HUB_OFFLINE=1`. Без водяного знака, как у дублей
D91 (поле лицензии в `AI-LOG.csv`).

## 4. Радиоцепочка (всё наше, numpy)

1. Тишина обрезана только с обоих концов (внутренние паузы сохранены: это
   предложения), фильтр высоких частот 90 Гц.
2. **Полоса 300-3400 Гц** (форма Баттерворта 4-го порядка, минимальная фаза,
   `gen_weapon_sfx.filt` проекта) с резонансом динамика +3 дБ на 1,4 кГц;
   **насыщение tanh** (drive 2,2, выходная лампа); вторая, более мягкая полоса
   (диффузор).
3. Выровнено: самые громкие 50 мс с A-взвешиванием на −14 дБ, пик <= −1 dBFS.
4. Аппарат: **ламповый фон 50 Гц** с нечётными гармониками, мягкое шипение,
   ~2,5 треска в секунду, медленное колебание приёма ±1 дБ, всё через ту же
   полосу.
5. **Настройка на станцию** 0,55 с перед голосом: статические помехи
   расчищаются, пока гетеродинный свист скользит к нулевым биениям; 0,35 с
   помех после.
6. **Позывные станции**, отдельно (три предложения, J1-J3): FM-колокола,
   **оригинальный** мотив. Это не настоящий позывной Радио «Москва», который
   является охраняемой песней 1930-х; здесь ничто его не цитирует.
7. **Сигнал точного времени** для RAD16: шесть сигналов по 1 кГц с интервалом
   в секунду, последний долгий. Технический сигнал, без автора.

## 5. Предложение по интеграции (для `mod-engineer`, `level-designer`; не построено)

### 5.1 Почему новый актор, а не `SD_Radio`

`SD_Radio` (MOD-SPEC §6.7, ADR 008) **подменяет музыку**; громкоговоритель
должен **добавить позиционный голос поверх музыки**, то есть это звук, а не
смена музыки. Собственные вещи `AmbientSound` GZDoom (14001-14064 с `$ambient`)
играют вечно с начала карты и не умеют ни плейлист, ни джингл при приближении,
поэтому предлагается небольшой актор на ZScript.

### 5.2 `SD_Loudspeaker`

| Что | Предложение |
|---|---|
| Класс, файл | `SD_Loudspeaker`, `zscript/sd/loudspeaker.zs` |
| Номер в редакторе | **21201** (следующий в блоке декораций, MOD-SPEC §6.1); строка `DoomEdNums` в `MAPINFO` — за PM |
| `arg0`, плейлист | индекс в таблице в ZScript (§5.4); `0` = все одобренные реплики |
| `arg1`, радиус | расстояние в 3D до игрока, при котором он включается; `0` = **384** (`SD_LS_DEFAULT_REACH`) |
| `arg2`, пауза | секунды тишины между репликами; `0` = **6** (`SD_LS_DEFAULT_PAUSE`) плюс случайные 0-4 с |
| `arg3`, флаги | бит 1 = без джингла; бит 2 = скрытое тело (для динамика, нарисованного на текстуре стены) |
| Включается | каждые 8 тиков измеряет `Distance3D` до `players[consoleplayer].mo`; в первый раз, когда игрок в радиусе: `A_StartSound("sd/radio/jingle", CHAN_VOICE, CHANF_DEFAULT, SD_LS_VOLUME, SD_LS_ATTN)`, плюс статическая подложка `sd/radio/bed` на `CHAN_BODY` с `CHANF_LOOPING` на меньшей громкости |
| Играет | когда `IsActorPlayingSound(CHAN_VOICE)` ложно и пауза прошла, следующая реплика его плейлиста из **мешка с перетасовкой** (все реплики по разу, прежде чем начнутся повторы; никогда одна и та же реплика дважды подряд) |
| Выключается | дальше, чем **радиус + 128** (`SD_LS_HYSTERESIS`): новая реплика не начинается; идущая реплика **доигрывается** (обрыв предложения на полуслове звучит как баг), затем `A_StopSound(CHAN_BODY)` |
| Возвращение | джингл играет снова только после **60 с** отсутствия (`SD_LS_JINGLE_COOLDOWN`), чтобы вход и выход не звонили им каждый раз |
| Громкость, затухание | `SD_LS_VOLUME` 0,7, чтобы звуки обнаружения и атаки врагов оставались сверху; никогда `ATTN_NONE` (в отличие от кличей боссов). SNDINFO `$rolloff sd/radio linear 128 768` на всё семейство `sd/radio/*`: полная громкость в пределах 128, тишина на 768 (**НЕ ПРОВЕРЕНО**, что `$rolloff` применяется к каждому члену по префиксу; иначе по строке на логическое имя) |
| Перекрытие | ограничения вроде `$limit sd/radio/line 1` не работают через перетасовку отдельных имён, поэтому правило — размещение: зоны «радиус + 128» двух динамиков не должны пересекаться (как у `SD_Radio`) |
| Тело | декорация, радиус 12, высота 24, `+SOLID` только когда стоит на полу; при бите 2 arg3: `+NOINTERACTION`, невидимо, для рупора, нарисованного на стене |
| Спрайт | рупорный громкоговоритель («колокол»), настенный или на столбе, `SDLS` A (art-director; до тех пор заглушка из IWAD). Либо текстура стены `SDLSPK1` со скрытым телом перед ней |
| Сохранённые игры | позиция мешка перетасовки, флаг «включён» и таймер перезарядки сохраняются; поле `transient` перезапускает подложку после загрузки, как делает `SD_Radio` (**НЕ ПРОВЕРЕНО**, восстанавливает ли движок зацикленные звуки акторов сам) |
| Одиночная игра | слушатель — локальный игрок, как у `SD_Radio` |
| Не простреливается | он наш (советское радио), не вражеский. Простреливаемый вариант, который умирает во взрыве помех, — возможное приятное дополнение V3, решает CEO |

### 5.3 Эскиз SNDINFO (лампы `SDRAD01`-`SDRAD16`, `SDRADJ1`, `SDRADPIP`, `SDRADBED`)

```
sd/radio/line/01  SDRAD01      // one logical name per line: the actor shuffles them
...
sd/radio/line/16  SDRAD16
sd/radio/jingle   SDRADJ1      // or a $random of the approved jingles
sd/radio/pips     SDRADPIP     // played before RAD16 only
sd/radio/bed      SDRADBED     // 4-6 s seamless loop of hum + hiss + crackle (to make, procedural)
$rolloff sd/radio linear 128 768
```

Если CEO одобрит больше одного дубля реплики, дубли становятся группой
`$random` под именем этой реплики (как голоса врагов, D91), а имена лампов
получают цифру-член (`SDRAD01A`, `SDRAD01B`).

### 5.6 Тесты, добавляемые вместе со сборкой (для `mod-engineer`)

## 6. Размер

каждая (§8). Установленный набор (16 реплик, один джингл, сигналы времени,
подложка) занимает около **1,1 МБ** PK3; больше, если CEO оставит несколько
