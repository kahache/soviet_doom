# Агрессивные мужские голосовые референсы для Chatterbox: источники-кандидаты

Каноническая версия: `docs/sound/2026-10-20_1234_P2_aggressive-voice-references.md`.

Владелец: `sound-designer`. 2026-10-20 12:34, фаза P2. Только исследование:
ничего не скачано, ничего не подготовлено. Решения, которым это служит:
**D36** (настоящий немецкий для Рейха, настоящий английский для Легиона
Свободы, любой ИИ-голос вносится в реестр лицензий), **D85/D87** (Chatterbox
Multilingual), **D91** (дубли получаются плоскими, потому что Chatterbox
копирует эмоцию референсного клипа, а предустановленные голоса — спокойная
дикторская начитка).

## 0. Что мы ищем и какие правила применены

- **Применение:** клип длиной 10-20 с одного мужского говорящего, кричащего или
  от боли, подаётся в Chatterbox как голосовой промпт. Сам клип никогда не
  поставляется; поставляются сгенерированные дубли, под CC BY-NC-SA 4.0 (D15).
- **Лицензионный фильтр** (`docs/sound/MUSIC-RIGHTS.md` §1.3): пригодно =
  общественное достояние, CC0, CC BY, CC BY-NC, CC BY-NC-SA. **Отклоняется =
  CC BY-SA** и всё без заявленной лицензии. Всё прочее (OpenRAIL) выносится на
  решение PM/CEO.
- **Этический фильтр:** никаких известных людей, никаких записей реальных
  исторических режимов (D11, D12), никаких ИИ-сгенерированных источников (они
  цепляли бы вывод одной модели к другой с неясным происхождением).
  Предпочтительны исполнители, явно выпустившие свой голос для повторного
  использования, лучше всего — для синтеза речи или для игр.
- **Язык важен для клонирования.** README Chatterbox Multilingual советует,
  чтобы референсный клип совпадал с целевым языком; иначе на выходе остаётся
  акцент языка референса. Он предлагает `cfg_weight=0`, чтобы это смягчить. То
  есть для немецких реплик нужен немецкий референс, для английских —
  английский. (Пересказано по памяти README, в этой сессии не перепроверено.)
- **Заметка для PM:** тот же README рекомендует `exaggeration` около 0,7 и
  выше и `cfg_weight` около 0,3 для драматичной речи. Exaggeration усиливает
  эмоцию, уже имеющуюся в референсе. Из спокойного референса крик он создать
  не может, что согласуется с D91, но его стоит поднять, когда у нас появится
  агрессивный референс.

## 2. Лучшие варианты по языкам, со ссылками на скачивание

### Немецкий

1. **Thorsten emotional, стиль `angry` (D1).** Скачивание:
   `https://zenodo.org/records/5525023/files/thorsten-emotional_v02.tgz?download=1`
   (399,3 МБ, md5 `f19585f3759c6d026757c46024a37aa4`). Зеркало: https://openslr.org/110/.
   Нарезка: извлечь только папку angry. Выбрать на слух 4-6 самых горячих
   клипов (восклицания, короткие предложения). Склеить с паузами 0,25 с до
   12-18 с. Передискретизировать до 24 кГц моно для Chatterbox (его частота
   дискретизации). Эквализацию не добавлять: материал уже нормализован.
2. **Thorsten `angry` + tontoepfer (D1 + D2): не рекомендуется.** Это два
   разных мужчины. Никогда не смешивать говорящих в одном референсе. D2
   использовать только для немецкого дубля, где чистая ярость важнее единства
   тембра: зациклить 2-3 раза с разными паузами (около 8 с) и ожидать более
   слабого клона.
3. **Запасной путь, если (1) звучит слишком вежливо:** взять самый сильный
   английский референс (E3 или E2) с `language_id="de"` и `cfg_weight=0`, затем
   оценить акцент на слух. Немецкий солдат с английским акцентом — известный
   риск (§0).
4. **Настоящим решением остаётся D85:** собственный немецкий крик CEO (15 с).
   `VOICE-SCRIPT.md` §0.2-0.4 уже говорит, как его записать.

## 4. Как нарезать референс на 10-20 с (любой источник)

Локальные инструменты — ffmpeg и/или Audacity. Пути к файлам кладутся в
`work/audio/voice_refs/` (в gitignore, никогда в `src/`).

1. **Только один говорящий.** Никогда не смешивать двух людей, даже если оба
   злы.
2. **Сухо и чисто:** без реверберации, музыки, стрельбы и радиофильтра
   (Chatterbox клонирует и комнату тоже). Брать варианты «NO reverb».
3. Обрезать тишину в начале и в конце. Ограничить внутренние паузы примерно
   0,3 с:
   ```
   ffmpeg -i in.wav -af "silenceremove=start_periods=1:start_threshold=-45dB:stop_periods=-1:stop_duration=0.3:stop_threshold=-45dB" trimmed.wav
   ```
4. Склеить клипы (файл списка со строками `file 'a.wav'`, короткие паузы
   между ними):
   ```
   ffmpeg -f concat -safe 0 -i list.txt -ac 1 -ar 24000 -af "loudnorm=I=-18:TP=-2" ref_<lang>_<source>.wav
   ```
   Пик не менее чем на 2 дБ ниже полной шкалы. **Никогда не клиппировать.**
   Искажённый референс клонирует искажение.
5. Цель — 12-18 с. Короче 8 с тембр нестабилен; длиннее 20 с ничего не
   добавляет.
6. Делать **два референса на голос**: *приказы* (выкрикиваемые слова) и *боль*
   (вопли). Реплики боли/смерти были худшими в D91.
7. Записывать происхождение каждого референса в
   `work/audio/voice_refs/REFS.csv`: URL источника, лицензия, SHA-256
   исходной загрузки и какие клипы вошли.
