## 2. Два решения, разблокирующие работу

- **Пакет ударов Kenney.** Звуки врагов используют 17 его файлов (разрешено
  D36); генератор звуков оружия его не взял, потому что условия инструмента,
  которым пакет сделан, не подтверждены. Одно правило для обоих: оставить
  Kenney [PM рекомендует «да»] или заменить эти слои другим пакетом CC0
  (около одной сессии).
- **Партитуры для трёх произведений, секвенируемых самими** («Вы жертвою
  пали», «Амурские волны», «Патриотическая песня» Глинки, D43). Читаемой
  нотной записи общественного достояния без скачивания нет. (a) Разрешить
  скачать по одной партитуре общественного достояния на произведение,
  сначала назвав размеры [рекомендовано] или (b) написать их по памяти с
  пометкой НЕ ПРОВЕРЕНО, с проверкой человеком, знающим эти мелодии.

Всё ещё открыто из проектного документа §13, без спешки: никаких ключей
(рекомендовано «да»); полоса ночного неба над ангаром, да или нет.
