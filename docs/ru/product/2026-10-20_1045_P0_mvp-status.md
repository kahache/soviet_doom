## 3. Критический путь

1. **Перерисовка ледоруба и OK CEO** (N14-AX, D84): единственный пункт M2 без
   одобрения. Остальные четыре оружия были одобрены в D84.
2. **Очередь установок mod-engineer**, последовательная, потому что установки
   делят файлы (LANGUAGE, SNDINFO, LICENSES, MOD-SPEC, `zscript.txt`):
   M2a-i → M2b-i → M2c-i → N9e → N14-I и ледоруб → установка M2e (N14-I можно
   поставить раньше, BACKLOG). Около 1 700k из 3 050k проходит через эту одну
   очередь.
3. **M2e** — самый большой ещё не начатый блок (свипа нет); его графику можно
   начинать параллельно уже сейчас, его установка встаёт в очередь.
4. **N11** после появления последней строки (строки подбора M2a-i, строки
   выхода M2e), затем **N16** и «публиковать» от CEO.
