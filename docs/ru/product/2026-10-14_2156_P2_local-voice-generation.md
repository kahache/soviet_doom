## 1. Рекомендация

**Сначала установить Chatterbox (от Resemble AI) с сервером веб-интерфейса
«Chatterbox-TTS-Server» в `Z:\Chatterbox`, используя 10-15 секунд ВАШЕГО
собственного голоса как референсный голос.**

Почему именно он, а не другой:

1. **Это единственный, кто выполняет сразу все четыре наших требования**:
   немецкий, английский и русский в одной модели (Chatterbox Multilingual, 23
   языка, ПРОВЕРЕНО по карточке модели); регулятор **эмоции/интенсивности**
   («Exaggeration», от 0,25 до 2), позволяющий перейти от бормотания к лаю;
   он легко помещается в 8 ГБ (около 3,5 ГБ VRAM по документации NVIDIA для
   этой модели, НЕ ПРОВЕРЕНО на этом ПК); и запускается двойным щелчком с
   портативным режимом, как Fooocus.
2. **Чистая лицензия**: код и веса под лицензией **MIT** (ПРОВЕРЕНО на GitHub
   и на Hugging Face, поле `License: mit`). MIT не накладывает условий на
   генерируемое аудио, так что оно подходит нашему пакету под CC BY-NC-SA 4.0
   (D15). Sound-designer подтверждает это по вашему журналу (`VOICE-SCRIPT.md`
   §0.7).
3. **Решает проблему акцента**: с вашим голосом в качестве референса модель
   произносит «Stellung halten» или «Vorwärts» на правильном немецком вашим
   тембром. Никакого карикатурного немецкого (D11).

Два предупреждения, которые не являются недостатками, но их нужно знать:

- **Каждый аудиофайл несёт неслышимый водяной знак** (PerTh, от Resemble AI;
  ПРОВЕРЕНО в их README). Вы его не слышите, он не мешает; мы отмечаем его в
  журнале.
- **Используйте в качестве референса только свой собственный голос.** Голоса,
  которые идут по умолчанию (например, на немецком — образец женского голоса),
  происходят, согласно самому README, из "freely available data on the
  internet", а сервер поставляется с папкой «predefined voices», происхождение
  которой не задокументировано. Ни то ни другое использовать нельзя: мы не
  знаем, чей это голос (`VOICE-SCRIPT.md` §0.7, «никогда не клонировать голос
  другого человека»). Клонированный голос — всё равно ваш голос: ваша фраза
  «las publico bajo CC BY-NC-SA 4.0» (CEO: «я публикую их под CC BY-NC-SA 4.0»)
  по-прежнему необходима.

**Второй инструмент: пока никакого.** Ни один генератор голоса хорошо не делает
стоны боли и последний вздох солдата (6 строк без слов: R07, R08, L07, L09, G03,
G04). Быстрее всего записать эти шесть на телефон (около 10 минут; шум горла,
ничего узнаваемого), а при неудаче у нас уже есть скачанный запасной вариант
CC0 (`ENEMY-SOUNDS.md` §5). Если всё же хочется попробовать ИИ для криков,
кандидат — **Dia** (Nari Labs, Apache 2.0, только английский, ~4,4 ГБ VRAM,
теги для крика, вздоха и выдоха; ПРОВЕРЕНО в их README), но у него нет
проверенного установщика в один клик: это делалось бы позже, через Pinokio.
**Applio** (преобразование голоса) имеет смысл, только если хочется, чтобы ваши
дубли звучали как *другой* человек, а это требует голосовой модели того, кто
дал согласие; см. §2.

## 3. Пошаговая установка (Chatterbox-TTS-Server)

### 3.0 Что я уже проверил на вашем ПК (ПРОВЕРЕНО, 2026-10-14)

| Пункт | Состояние |
|---|---|
| Видеокарта | NVIDIA GeForce RTX 3050, 8192 МиБ, драйвер 560.94 (сервер требует 525 или выше для 30-й серии) |
| Свободное место на `C:` | **11,3 ГБ: почти полный.** Ничего из этого не должно попадать на `C:` |
| Свободное место на `Z:` | **153,8 ГБ**: всё идёт сюда, рядом с `Z:\Fooocus` |
| Git | Установлен (2.55) |
| Системный Python | 3.14.6. Это нормально: сервер использует его только для запуска, а затем приносит свой портативный Python 3.10 |
| ffmpeg | Установлен (`C:\ProgramData\chocolatey\bin\ffmpeg.exe`) |
| Уже установленные голосовые инструменты | **Никаких.** Я посмотрел в `Z:\`, на вашем Рабочем столе, в `%LOCALAPPDATA%\Programs` и `C:\Program Files`: там есть Fooocus, Ollama, Python и папка `whisper` в кэше (это распознавание речи, а не генерация) |

**Важно:** по умолчанию программа хранит модели (около 4-6 ГБ) и кэш загрузок в
`C:\Users\littl\.cache` и в `AppData`, то есть на `C:`, где всего 11 ГБ.
Поэтому на шаге 3 мы создаём лаунчер, который говорит ей хранить всё на `Z:`.
**Всегда запускайте через этот лаунчер, в первый раз тоже.**

**Не держите Fooocus открытым одновременно**: они будут бороться за 8 ГБ
карты.

### 3.1 Шаг 1: откройте PowerShell

Клавиша Windows, наберите `PowerShell`, нажмите Enter (запуск «от имени
администратора» не нужен; лучше без него). Скопируйте и вставьте каждый блок
ниже и нажимайте Enter.

### 3.2 Шаг 2: скачайте программу в `Z:\Chatterbox`

Официальная страница проекта: <https://github.com/devnen/Chatterbox-TTS-Server>

```powershell
New-Item -ItemType Directory -Force "Z:\Chatterbox"
New-Item -ItemType Directory -Force "Z:\Chatterbox\hf_cache"
New-Item -ItemType Directory -Force "Z:\Chatterbox\pip_cache"
New-Item -ItemType Directory -Force "Z:\Chatterbox\tmp"
git clone https://github.com/devnen/Chatterbox-TTS-Server.git "Z:\Chatterbox\Chatterbox-TTS-Server"
```

Если `git clone` выдал ошибку, альтернатива без Git: на странице проекта зелёная
кнопка **Code → Download ZIP**, и распакуйте ZIP так, чтобы существовала папка
`Z:\Chatterbox\Chatterbox-TTS-Server` (с `start.bat` внутри, а не на одну
папку глубже).

### 3.3 Шаг 3: создайте лаунчер, который хранит всё на `Z:`

Вставьте весь этот блок (от `@'` до `'@` включительно):

```powershell
@'
@echo off
set HF_HOME=Z:\Chatterbox\hf_cache
set PIP_CACHE_DIR=Z:\Chatterbox\pip_cache
set TEMP=Z:\Chatterbox\tmp
set TMP=Z:\Chatterbox\tmp
cd /d Z:\Chatterbox\Chatterbox-TTS-Server
call start.bat
'@ | Set-Content -Encoding ascii "Z:\Chatterbox\arrancar-chatterbox.bat"
```

Это создаёт `Z:\Chatterbox\arrancar-chatterbox.bat`. Он лишь меняет место, где
эта программа хранит данные; в Windows он ничего не трогает.

### 3.4 Шаг 4: ярлык на Рабочем столе

```powershell
$atajo = (New-Object -ComObject WScript.Shell).CreateShortcut("C:\Users\littl\Desktop\Chatterbox.lnk")
$atajo.TargetPath = "Z:\Chatterbox\arrancar-chatterbox.bat"
$atajo.WorkingDirectory = "Z:\Chatterbox\Chatterbox-TTS-Server"
$atajo.Save()
```

На Рабочем столе появится значок **Chatterbox**, рядом со значком Fooocus.

### 3.5 Шаг 5: первая установка (только один раз, 15-40 минут)

1. Дважды щёлкните значок **Chatterbox** на Рабочем столе. Откроется чёрное
   окно.
2. Оно спрашивает, хотите ли вы **портативный режим** (Portable Mode). Это
   вариант по умолчанию: нажмите **Enter**.
3. Оно обнаруживает карту NVIDIA и показывает меню. Вариант по умолчанию —
   `[2] NVIDIA GPU (CUDA 12.1)`, он подходит для RTX 3050: нажмите **Enter**.
4. Подождите. Оно скачивает Python, PyTorch и всё остальное (несколько ГБ).
   Если Windows Defender или брандмауэр спросят, разрешите доступ только в
   **частных сетях**.
5. Когда закончится, окно покажет адрес программы. При первой генерации оно
   также скачает модель (ещё около 2-4 ГБ) в `Z:\Chatterbox\hf_cache`.

Точные формулировки каждого вопроса в шагах 2-3 взяты из README проекта;
текст на экране может немного отличаться (НЕ ПРОВЕРЕНО на этом ПК, я ничего
не устанавливал).

### 3.6 Шаг 6: откройте интерфейс

Откройте в браузере **<http://localhost:8004>**

(Fooocus использует другой порт, 7865, так что они не конфликтуют; но помните,
что из-за карты их не нужно держать открытыми одновременно.)

### 3.7 Повседневное использование

- Запуск: дважды щёлкните значок **Chatterbox**. В следующие разы он обнаружит,
  что уже установлен, и запустится сразу.
- Открыть: <http://localhost:8004>
- Закрыть: закройте чёрное окно (или нажмите `Ctrl+C` внутри него).

### 3.8 Если что-то не работает

- **Выберите многоязычную модель.** Вверху интерфейса есть селектор движка
  (Original / Turbo / Multilingual), а при многоязычном — выпадающий список
  языков. Если он не появился, откройте в Блокноте
  `Z:\Chatterbox\Chatterbox-TTS-Server\config.yaml`, найдите `repo_id:` в
  разделе `model:` и задайте `repo_id: multilingual`; сохраните, закройте
  чёрное окно и запустите снова.
- Если окно пишет «Python 3.10+ not found», откройте PowerShell и наберите
  `python --version`: должно показать 3.14.6. Если показывает, сообщите мне с
  фотографией окна.
- Если не хватает видеопамяти: закройте Fooocus, браузер с множеством вкладок
  и любую игру.

## 4. Как использовать его для наших реплик

### 4.1 Прежде всего: ваш референсный голос (10 минут, один раз)

1. Запишите на телефон, как сказано в `VOICE-SCRIPT.md` §0.2-§0.4 (сухая
   комната, 20-30 см), **два клипа по 10-15 секунд**, говоря спокойно:
   - `ceo_ref_de`: медленно прочитайте немецкие реплики из §0.6
     `VOICE-SCRIPT.md` (Stellung halten, Augen auf, Ruhe da hinten,
     Vorwärts...), как получится.
   - `ceo_ref_en`: прочитайте реплики Легиона по-английски (Sector four,
     clear. Copy. Holding position...).
   Почему два: README предупреждает, что если референс на другом языке, чем
   текст, акцент референса просачивается. Если вы предпочитаете один клип на
   испанском, тогда задайте **CFG равным 0** (README рекомендует это, чтобы
   избежать акцента) ценой меньшего контроля над ритмом.
2. Преобразуйте их в моно WAV (сервер принимает `.wav` и `.mp3`; если телефон
   выдаёт `.m4a`, преобразуйте). Пример, заменив исходные пути на свои:

   ```powershell
   ffmpeg -i "C:\Users\littl\Desktop\ceo_ref_de.m4a" -ac 1 -ar 24000 "Z:\Chatterbox\Chatterbox-TTS-Server\reference_audio\ceo_ref_de.wav"
   ffmpeg -i "C:\Users\littl\Desktop\ceo_ref_en.m4a" -ac 1 -ar 24000 "Z:\Chatterbox\Chatterbox-TTS-Server\reference_audio\ceo_ref_en.wav"
   ```

   (Их можно также загрузить из интерфейса, в режиме клонирования голоса:
   «Voice Cloning», кнопка загрузки файла.)
3. В интерфейсе: режим **Voice Cloning**, выберите свой клип. **Никогда** не
   используйте голоса «Predefined Voices» или образец голоса, который
   подставляется по умолчанию при смене языка.

### 4.2 Регуляторы, которые важны

Имена по README и примеру приложения Resemble AI; начальные числа — те, что сам
README рекомендует для выразительной речи. Остальное — **ГИПОТЕЗА**, пока вы
этого не услышите.

| Регулятор | Что делает | Бормотание (покой) | Лай (тревога) | Генерал |
|---|---|---|---|---|
| **Exaggeration** (0,25-2; по умолчанию 0,5) | Эмоциональная интенсивность. Выше = интенсивнее и быстрее | 0,3-0,4 | **1,0-1,4** | 0,3 |
| **CFG / CFG Weight** (0-1; по умолчанию 0,5) | Насколько близко держаться референса и ритма. Его понижение компенсирует спешку, вызываемую Exaggeration | 0,5 | **0,3** | 0,5-0,6 |
| **Temperature** (по умолчанию 0,8) | Вариативность между дублями. Выше = живее, больше сбоев | 0,8 | 0,9-1,0 | 0,6 |
| **Seed** (0 = случайный) | Зафиксируйте его, когда дубль понравился, чтобы можно было повторить и записать в журнал | — | — | — |
| **Speed Factor** | Скорость. Лучше оставить 1 и дать sound-designer подстроить | 1 | 1 | 1 |

Приём с текстом (ГИПОТЕЗА, типичная для этих моделей): одно очень короткое
слово иногда выходит с мусором в конце. Если «Feind!» выходит странно, напишите
`Feind! Feind!`, и sound-designer вырежет одно. Пунктуация имеет значение: `!`
толкает к крику, `.` к спокойствию, `...` растягивает и затухает.

### 4.3 Примеры с тремя строками сценария

**R04 — `SDRRISIT` — «Feind!» (стрелок Рейха, громкий лай, ≤ 0,5 с, 5 дублей)**

- Движок: Multilingual. Язык: **немецкий (de)**. Голос: `ceo_ref_de.wav`.
- Текст: `Feind!`
- Exaggeration 1,2 · CFG 0,3 · Temperature 0,9 · Seed 0.
- Сгенерируйте 8-10 раз и оставьте 5 самых сухих. Это должно звучать как
  солдат, дающий предупреждение, а не как киношный злодей (D11): если звучит
  театрально, понизьте Exaggeration до 0,9.

**G02 — `SDGENSUM` — «Vorwärts.» (Генерал, реплика, которую игрок должен понять, ≤ 1,2 с, 8 дублей)**

- Движок: Multilingual. Язык: **немецкий (de)**. Голос: `ceo_ref_de.wav`.
- Текст: `Vorwärts.` (с точкой, никогда не с восклицательным знаком: он не
  кричит).
- Exaggeration 0,3 · CFG 0,6 · Temperature 0,6.
- Не пытайтесь сделать голос низким: sound-designer понизит его на 4
  полутона потом (`GENERAL-SLOT`). Важно лишь, чтобы слово было понятно.

**L04 — `SDLTRSIT` — «Contact!» (солдат Легиона, по радио, ≤ 0,6 с, 5 дублей)**

- Движок: Multilingual, язык **английский (en)**, либо движок **Turbo**
  (только английский). Голос: `ceo_ref_en.wav`.
- Текст: `Contact!`
- Exaggeration 1,1 · CFG 0,3 · Temperature 0,9.
- Чёткие согласные: радио (`LEGION-RADIO`) съедает низы и верхи.

### 4.4 Крик и предсмертный возглас

В нашем сценарии **никто не умирает с криком**: R08 и L09 — это ломающееся
дыхание, G04 — долгий выдох, затухающий, как у машины. С Chatterbox:

| Что вам нужно | Текст | Регуляторы | Ожидание |
|---|---|---|---|
| Лай / крик тревоги | Короткое слово с `!` | Exaggeration 1,0-1,4, CFG 0,3 | Хорошо (ГИПОТЕЗА) |
| Боль (R07, L07, G03) | `Ngh!` / `Agh!` / `Hm.` | Exaggeration 1,0, CFG 0,3 | **Слабо**: может прочитать как слово |
| Смерть (R08, L09, G04) | `Hhh... ah...` / `Sani...` (R09) | Exaggeration 0,6, CFG 0,3, Temperature 1,0 | **Слабо**; R09 «Sani...» должна получиться |

Для 6 строк без слов реалистично записать их самому (10 минут) или оставить
запасной вариант CC0. Пробуйте ИИ, если хочется, но не тратьте на это больше
короткого времени.

### 4.5 Куда сохранять и как называть

1. Каждый понравившийся дубль: кнопка скачивания плеера интерфейса (он попадает
   в вашу папку Загрузки).
2. Переместите его в папку, которую читает sound-designer,
   **`work/audio/voice_takes/`** репозитория (`VOICE-SCRIPT.md` §0.5; она в
   gitignore, в git не попадает):

   ```powershell
   New-Item -ItemType Directory -Force "C:\Users\littl\Desktop\Claude\soviet_doom\work\audio\voice_takes"
   Move-Item "C:\Users\littl\Downloads\<name-it-gave-you>.wav" "C:\Users\littl\Desktop\Claude\soviet_doom\work\audio\voice_takes\R04_SDRRISIT_ai_chatterbox_20261014_t01.wav"
   ```

3. Имя: то, что в `VOICE-SCRIPT.md` §0.5 для ИИ,
   `<row>_<lump>_ai_chatterbox_<date>.wav`, плюс `_t01`, `_t02`..., потому что
   здесь каждый дубль выходит отдельным файлом (моё предложение;
   sound-designer решает, принять ли его). Храните их **ровно так, как они
   выходят**, без правки.
4. **Обязательный журнал** (`VOICE-SCRIPT.md` §0.7): одна строка на файл в
   `work/audio/voice_takes/AI-LOG.csv`. Заголовок и пример:

   ```
   fichero;herramienta;version_o_modelo;fecha;plan;licencia_de_uso;voz;texto;ajustes
   R04_SDRRISIT_ai_chatterbox_20261014_t01.wav;Chatterbox-TTS-Server (github.com/devnen/Chatterbox-TTS-Server) + Chatterbox Multilingual (Resemble AI);<the model the interface shows>;2026-10-14;free, local;MIT, https://huggingface.co/ResembleAI/chatterbox, read 2026-10-14, "Licensed under MIT";cloned from my own voice (ceo_ref_de.wav);Feind!;de, exaggeration 1.2, cfg 0.3, temperature 0.9, seed <whichever comes out>
   ```

5. И строка в обычном чате: «Las tomas de voz son mías y las publico bajo CC
   BY-NC-SA 4.0 (D15)» (заявление CEO: «Дубли голоса мои, и я публикую их под
   CC BY-NC-SA 4.0 (D15)»). Без неё не используется ни один, ни записанный, ни
   сгенерированный вашим голосом.
