# Индекс текстур

Живой документ. Владелец: `art-director`. Контракт с `level-designer` и
`mod-engineer`: имя лампа из этой таблицы — то имя, которое используют карта и
PK3. **Переименование = сначала обновить таблицу, потом файл.** Английский
оригинал: `docs/art/TEXTURE-INDEX.md`.

Статусы: `proposed` (в превью, ещё не в `assets/`), `approved` (CEO сказал
«да»; файл лежит в `assets/`), `discarded` (CEO сказал «нет»; причина
сохранена, чтобы не предлагать снова), `IWAD` (ссылка по имени на базовый
IWAD, ничего не распространяется).

Коды происхождения (ART-BIBLE §2): (a) собственный процедурный скрипт +
зерно, (b) свободный пак с лицензией, (c) материал CEO.

Не в этой партии (намеренно): всё, что относится к двум вражеским фракциям
(F5), экстерьеры/небо, анимированные текстуры и переключатели
(ANIMDEFS/SWITCHES — зона `mod-engineer`, предлагаются в партии 2 после
одобрения базового набора).

Кандидаты в партию 2 (не начаты): стена с крашеным «фартуком» (зелёная
масляная краска снизу + побелка сверху), угол/пилястра из бетона,
ящик/шкафчик, вариант стальной двери под ключи (красная/жёлтая/синяя
окантовка), наружный бетон с ночным небом, сталь стартовой фермы, панель
переключателя.
