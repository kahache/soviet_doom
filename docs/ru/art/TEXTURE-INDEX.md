# Индекс текстур

Живой документ. Владелец: `art-director`. Контракт с `level-designer` и
`mod-engineer`: имя лампа из этой таблицы — то имя, которое используют карта и
PK3. **Переименование = сначала обновить таблицу, потом файл.** Английский
оригинал: `docs/art/TEXTURE-INDEX.md`.

Синхронизировано с оригиналом: 2026-10-27.

Статусы: `proposed` (в превью, ещё не в `assets/`), `approved` (CEO сказал
«да»; файл лежит в `assets/`), `discarded` (CEO сказал «нет»; причина
сохранена, чтобы не предлагать снова), `IWAD` (ссылка по имени на базовый
IWAD, ничего не распространяется). Переходные статусы, всегда с причиной:
`pending in-map review` (CEO решает, увидев текстуру в GZDoom; для этой цели
и только для неё файл уже может лежать в `assets/` и в PK3 — одобренной он
от этого не становится), `approved pending …` («да» при условии, которое
CEO ещё должен подтвердить; в `assets/` ещё нет), `proposed vN`
(перерисована после вердикта, ждёт следующего; тоже может лежать в
`assets/` ради вердикта в карте, то же правило). Словарь статусов —
английский в обоих зеркалах; `tools/art/make_preview.py` читает эту колонку
и подписывает карточки превью.

Коды происхождения (ART-BIBLE §2): (a) собственный процедурный скрипт +
зерно, (b) свободный пак с лицензией, (c) материал CEO.

`work/`; при установке файлы переименованы в роли-имена движка по
собственному соглашению Doom: **1 = выкл, 2 = вкл, буква варианта
