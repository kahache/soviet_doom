## 3. Critical path

1. **The ice axe's redraw and the CEO's OK** (N14-AX, D84): the only M2
   item without an approval. The four other weapons were approved in D84.
2. **The mod-engineer's install queue**, serial because the installs share
   files (LANGUAGE, SNDINFO, LICENSES, MOD-SPEC, `zscript.txt`): M2a-i →
   M2b-i → M2c-i → N9e → N14-I and the ice axe → M2e's install (N14-I may be
   placed earlier, BACKLOG). About 1 700k of the 3 050k runs through this
   one queue.
3. **M2e** is the largest block not yet started (no sweep exists); its art
   can start in parallel now, its install joins the queue.
4. **N11** after the last string lands (M2a-i pickup lines, M2e quit lines),
   then **N16** and the CEO's "publish".
